# Business Bot Pro
نسخه اولیه عملیاتی ربات تلگرام چندکسب‌وکاره برای ثبت مشتری، شماره تماس، درخواست قیمت/سفارش، اعلان مدیر، مدیریت کاتالوگ و پاسخ‌گویی اختیاری هوش مصنوعی.

## امکانات و معماری
- یک ربات تلگرام برای چند برند؛ انتخاب کسب‌وکار در شروع
- ثبت نام و شماره تماس با دکمه اشتراک‌گذاری شماره
- ثبت درخواست قیمت و ارسال اعلان به مدیران همان برند
- پنل وب مدیریت با احراز هویت Basic برای کسب‌وکارها، مدیران، محصولات/خدمات و سفارش‌ها
- SQLite پیش‌فرض؛ PostgreSQL با تغییر DATABASE_URL
- پاسخ هوشمند اختیاری با OpenAI API؛ بدون کلید نیز سایر امکانات فعال‌اند
- Docker Compose یا اجرای مستقیم Python 3.11+

## راه‌اندازی
1. در تلگرام به @BotFather برو، دستور /newbot را اجرا و توکن بگیر.
2. `.env.example` را به `.env` کپی کن و BOT_TOKEN، ADMIN_USERNAME، ADMIN_PASSWORD و SECRET_KEY را تغییر بده.
3. نصب:
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```
4. اجرای ربات:
```bash
python -m app.bot
```
5. در ترمینال دوم اجرای پنل:
```bash
uvicorn app.admin:app --host 127.0.0.1 --port 8000
```
پنل: http://127.0.0.1:8000

## راه‌اندازی کسب‌وکارها
در پنل وارد شو و کسب‌وکار اضافه کن. نمونه slug:
- panahnoor
- tablo jadoo: `tablojadoo`
- petijoon

برای هر کسب‌وکار شناسه عددی تلگرام مدیران را با کاما در فیلد مدیران وارد کن. مدیر باید یک بار /start را برای ربات بفرستد تا ربات بتواند اعلان خصوصی ارسال کند. سپس محصولات و خدمات را ثبت کن. مشتری با /start برند را انتخاب می‌کند.

## هوش مصنوعی
در صورت داشتن API Key معتبر، `OPENAI_API_KEY` و `OPENAI_MODEL` را تنظیم کن. متن توضیحات کسب‌وکار در پنل به عنوان دانش پایه به دستیار داده می‌شود. دستیار اجازه ندارد قیمت، موجودی یا ضمانت را جعل کند؛ اطلاعات نامعلوم را به مدیر ارجاع می‌دهد.

## Docker
```bash
docker compose up -d --build
```
پنل در compose فقط روی localhost منتشر می‌شود؛ برای دسترسی بیرونی، HTTPS و reverse proxy مانند Caddy/Nginx تنظیم کن.

## جداول پایگاه داده
`businesses`, `customers`, `catalog_items`, `orders`, `conversation_messages`

## نکات مهم
- توکن ربات و کلید API را فقط در `.env` نگه دار و هرگز در چت یا مخزن عمومی منتشر نکن.
- رمز پیش‌فرض پنل را حتماً تغییر بده.
- برای انتشار واقعی، HTTPS، بکاپ منظم دیتابیس، محدودسازی دسترسی پنل و سیاست حریم خصوصی لازم است.
- شماره تماس فقط با رضایت مشتری دریافت شود.
- این نسخه پرداخت آنلاین، پیامک، فاکتور رسمی و ارسال انبوه تبلیغاتی ندارد.
- این پروژه برای شروع قابل اجراست اما پیش از استفاده تجاری گسترده، تست روی سرور و بازبینی امنیتی توصیه می‌شود.

## عیب‌یابی
- خطای BOT_TOKEN: فایل `.env` را بررسی کن.
- اعلان مدیر نمی‌رسد: شناسه عددی مدیر را درست وارد کن و مدیر باید قبلاً /start زده باشد.
- AI جواب نمی‌دهد: کلید API، اعتبار حساب و نام مدل را بررسی کن.
